# سلمية نحنا معك

مشروع Flask لإدارة منصة الدليل الخدمي والإعلاني والأخباري مع بوت Telegram.

## الملفات
- `app.py`: التطبيق ولوحة الإدارة والبوت.
- `requirements.txt`: المكتبات المطلوبة.
- `render.yaml`: إعداد النشر على Render.

## النشر على Render
1. ارفع الملفات الثلاثة إلى مستودع GitHub الخاص بالمشروع.
2. اربط المستودع بخدمة Render الحالية أو حدّث الخدمة الحالية من المستودع نفسه.
3. تأكد من وجود متغيرات البيئة التالية في Render:
   - `ADMIN_USER`: اسم حساب المالك الحالي.
   - `ADMIN_PASSWORD`: كلمة مرور المالك. لا تضعها في GitHub.
   - `BOT_TOKEN`: رمز بوت تلغرام. لا تضعه في GitHub.
   - `SECRET_KEY`: قيمة سرية طويلة وعشوائية.
   - `RUN_BOT_POLLING`: القيمة `true`.
4. لا تحذف خدمة Render الحالية ولا تنشئ قاعدة بيانات جديدة قبل التأكد من بياناتك القديمة.

## لوحة التحكم
- `/login`: تسجيل الدخول.
- `/dashboard`: الطلبات والإحصائيات.
- `/sections`: مدير القوائم الديناميكية.
- `/directory`: الدليل الخدمي.
- `/notifications`: إرسال الأخبار العاجلة والإشعارات.
- `/moderators`: إدارة المشرفين (للمالك فقط).

## أنواع القوائم
- محتوى الإدارة: المحلات والإعلانات وآخر الأخبار. يضيف المسؤول المنشورات ويخفيها أو ينشرها.
- طلبات المستخدمين: فرص العمل والعقارات وغيرها.
- الدليل الخدمي: يعرض بيانات الدليل الخدمي القديمة.

## ملاحظات مهمة قبل النشر
- هذا الإصدار يضيف جداول جديدة ويُبقي الجداول القديمة (`users`, `submissions`, `service_entries`) كما هي، ولا ينفذ حذفاً أو إعادة تهيئة لها.
- **التخزين:** SQLite على نظام الملفات المحلي قد لا يكون دائماً على Render إذا لم تكن الخدمة مرتبطة بقرص دائم. لا تعتبر البيانات آمنة بعد إعادة النشر/إعادة التشغيل قبل إعداد تخزين دائم أو قاعدة بيانات مُدارة. لا تحذف قاعدة البيانات الحالية.
- البوت يسجل المستخدم بعد أن يرسل `/start` أو أي رسالة. لا يستطيع إرسال إشعارات إلى من لم يبدأ البوت أو قام بحظره.
- الإشعارات تُرسل فوراً لجميع المستخدمين النشطين، وقد يستغرق الإرسال وقتاً حسب عددهم.
- الصور في المنشورات تُضاف عبر رابط صورة مباشر HTTPS.
- شغّل نسخة اختبارية وتأكد من ظهور لوحة التحكم والبوت قبل اعتماد النشر النهائي.
